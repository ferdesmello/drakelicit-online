# Open data — Drakelicit online

Every submission to the test, one row per person, published under
**[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)**: you may copy, share and reuse it,
including commercially, as long as you credit the source (suggested: "Drakelicit online, data
CC BY 4.0, https://github.com/ferdesmello/drakelicit-online") and say if you changed it.

Participants were told before submitting that their answers become public and cannot be removed.
No name, e-mail, IP address or time of day is stored here. The context fields are optional.

## Caveats before you use it

* **Self-selected, uncontrolled sample.** Anyone could answer, bots and repeat answers included.
  This is an "internet test", not a survey of a defined population.
* Rows are validated (ranges, one answer per parameter, uuid format), but values are still opinions of
  unknown people; `returning_self` / `returning_device` flag repeat participation, they do not remove it.
* `date` is the date reported by the participant's browser (UTC, date only). Implausible dates are replaced
  by the date of the monthly update that imported the row.
* The data is imported **once a month** (and whenever the maintainer runs the update by hand).

## Files

| File | What |
|---|---|
| `part-0001.jsonl`, `part-0001.csv`, ... | Submissions, 1000 per part, in arrival order. A part that is full ("frozen" in `manifest.json`) never changes again; the last part grows. The `.csv` is the same data, flattened. |
| `manifest.json` | List of parts, row counts, frozen or not, question order, license. |
| `community.json` | Pooled distribution of all participants, as drawn on the results page (see below). |
| `last_run.txt` | When the monthly update last ran, and whether the import succeeded. |

## Columns (CSV) / fields (JSONL)

| Field | Values |
|---|---|
| `id` | random uuid generated in the browser (not linked to a person) |
| `date` | `YYYY-MM-DD` |
| `lang` | `pt`, `en`, `es` (language of the page) |
| `consent` | version of the consent text accepted |
| `country` | ISO 3166-1 alpha-2 code, or empty |
| `area_grande` | CNPq broad field (Portuguese label), or empty. `Sem formação superior` = no higher education |
| `area_especifica` | CNPq "área do conhecimento" (Portuguese label, one of the 76 in `areas.json`), or empty. Only present together with a matching `area_grande`. E.g. `Geociências` vs `Física` |
| `familiarity_astro`, `familiarity_bio` | `none` `little` `moderate` `good` `expert` |
| `returning_self` | `yes`/`no`: "have you taken this test before?" (self-report) |
| `returning_device` | `True`/`False`: this browser had already sent an answer (automatic) |
| `belief_life_solar`, `belief_life_galaxy`, `belief_intel_galaxy`, `belief_life_universe`, `belief_intel_universe` | `very_unlikely` `unlikely` `unsure` `likely` `very_likely` |
| `<param>_t_lo`, `<param>_t_mode`, `<param>_t_hi`, `<param>_skipped` | for each of `Ns fp ne fl fi fc fL` (see below) |

### What `t_lo`, `t_mode`, `t_hi` mean

Each parameter is answered with a **truncated split-normal distribution** on `T = log10(parameter)`:

* `t_mode` — the peak (most likely value);
* `t_lo` / `t_hi` — the 10th / 90th percentile *of the untruncated half-normals* that define each side
  (`sigma_L = (t_mode - t_lo) / 1.2816`, `sigma_R = (t_hi - t_mode) / 1.2816`, at least 0.02);
* the distribution is cut at the axis limits of the question (`tMin`, `tMax` in `questions.json`) and renormalised;
* when a handle sits at a limit, `t_lo == tMin` or `t_hi == tMax`;
* if `_skipped` is true the three values are empty.

Parameters: `Ns` stars in the Milky Way, `fp` fraction with planets, `ne` habitable planets per star,
`fl` fraction with life, `fi` fraction developing intelligence, `fc` fraction capable of interstellar
communication, `fL` fraction of the star's lifetime the civilization is detectable. `N = Ns·fp·ne·fl·fi·fc·fL`.

## `community.json`

Linear opinion pool (equal-weight average) of every participant's distribution for each parameter, and a Monte
Carlo distribution of `N` built by sampling each pooled parameter independently. Generated by
`scripts/update_data.py` with a fixed seed, using the same maths as the website (`scripts/compute.py`).
`parameters.<id>.pdf` is sampled on `n_grid` equally spaced points from `t_min` to `t_max`;
`community_N.log_N_grid` / `.pdf` is the density of `log10(N)`.
